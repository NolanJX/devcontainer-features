# devcontainer-features

A collection of Dev Container Features.

## Contents

### `claude-code`

Installs the Claude Code CLI globally via npm ([@anthropic-ai/claude-code](https://www.npmjs.com/package/@anthropic-ai/claude-code)).

**Test:**

```shell
devcontainer features test -f claude-code --base-image mcr.microsoft.com/devcontainers/base:2.1.13-trixie
```
